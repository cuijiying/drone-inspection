# 一趟飞行，一份三维报告

给光伏电站无人机巡检班组长用的浏览器工具。载入一趟飞行的航迹和照片，在三维地球上回放航线，把缺陷钉在拍摄位置，并生成可以打印存档的一页报告。

不做飞控、机场、空域、UTM 或城市级数字孪生。

## 运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm start
```

浏览器打开 http://localhost:5173 。页面会自动载入龙羊峡示例架次，不需要先上传文件。

## 示例架次

示例是合成数据，飞在青海省海南州共和县塔拉滩、龙羊峡水光互补光伏电站 A 区上方：

- 航程约 6.80 公里，时长 24 分钟（2026-06-18 09:06–09:30，北京时间）
- 相对地面高度大约 86–106 米，便于在没有地形服务时回放
- 20 张缺陷照片，带拍摄时间和 GPS；部分缺陷故意略微偏离航线
- 同目录还有一份 KML，可用「上传航线」换着试

照片时间按北京时间写入 EXIF，航迹时间是 UTC，两者指向同一时刻。

## 怎么用

1. 点「播放」。勾选「镜头跟随」后，相机会跟在飞机后上方。
2. 右侧缺陷清单或地图图钉会把镜头飞到该点，并打开照片。等级、组件编号和备注可以改，会写进报告。
3. 「生成报告」得到一页纸。点「打印 / 导出 PDF」，在系统打印对话框里选择「另存为 PDF」。
4. 自己的数据：上传 GPX 或 KML，再上传带 GPS、拍摄时间的 JPEG。也可以把文件直接拖进页面。没有坐标、但有时间和航迹时，照片会按时间对齐到航线上。

空格键可以播放或暂停。

## 航迹和照片里读什么

- GPX：`trkpt` / `rtept` 的纬度、经度、`ele`、`time`
- KML：`gx:Track` 的 `when` + `gx:coord`，或 `LineString` 的 `coordinates`
- 照片：EXIF GPS、`DateTimeOriginal`（按北京时间）、可选的缺陷说明

示例照片把缺陷类型写在 `ImageDescription` 里。普通照片没有这段说明时，类型为「待确认」，可以在清单里改。

## 技术栈

TypeScript、Vue 3、CesiumJS、Vite。卫星底图使用 Esri World Imagery，需要能访问公网影像。三维高度使用航迹里的相对地面高度，不依赖 Cesium ion 地形。

重新生成示例数据（需要本机的 Python、Pillow、piexif 和中文字体）：

```bash
python3 scripts/generate_sample.py
```
